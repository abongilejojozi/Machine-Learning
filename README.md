## 📖 About
This repository documents my journey into **Machine Learning**. It contains a growing collection of practical exercises, experiments, and projects completed while learning core ML concepts. Topics explored include data preprocessing, exploratory data analysis, supervised and unsupervised learning, model evaluation, and applying libraries like NumPy, Pandas, and Matplotlib to real problems. Each project represents a step in developing my understanding of machine learning and applying it to solve practical problems.
